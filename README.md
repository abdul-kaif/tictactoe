# 🎮 Tic-Tac-Toe Game

A fun, interactive Tic-Tac-Toe game built with HTML, CSS, and JavaScript. Play against a friend, enjoy a clean interface, and challenge yourself to get three marks in a row!

## 🌐 Live Demo

**Play the game online:** https://tic-tac-toe-kaif-game.netlify.app/

## ✨ Features

- 🎯 Interactive 3×3 game board
- 👥 Two-player gameplay
- ❌ Player X and ⭕ Player O turns
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart and play again
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and lightweight — no backend required

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Styling, layout, and animations
- **JavaScript** — Game logic and interactions
- **Netlify** — Deployment and hosting

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three marks horizontally, vertically, or diagonally wins.
4. If all nine cells are filled without a winner, the game ends in a draw.
5. Click the restart button to play again.
